LightRAGへの入れ方

このアプリで作った Markdown(.md) を LightRAG に手作業で入れるときの手順と、サーバー側の推奨設定です。LightRAG 1.5.7 を主な対象にし、1.4.x との違いを注記しています。

エンティティ種別YAMLをダウンロード
{% set current = "lightrag" %}{% include "settings/_tabs.html" %}
{% call ui.card("1. サーバーのバージョンを確認する") %}

GET /health の応答でバージョンを確認します。バージョンによってファイルの扱いが違います。

項目1.5.x（主な対象）1.4.x
文書ID（doc_id）ファイル名の MD5内容の MD5
同じ名前のファイルHTTP 409 で断られる。変更したファイルは先に削除してから入れ直す内容が変われば別の文書として入る（古い方は手で削除）
エンティティ種別ENTITY_TYPE_PROMPT_FILE（YAML）。ENTITY_TYPES を書くと起動に失敗するENTITY_TYPES 環境変数（リスト）

このアプリのファイル名は、同じ帳票・同じ期間なら毎回同じになります（入れ替えの手順が単純になります）。

{% endcall %} {% call ui.card("2. サーバーの .env を設定する（最初に1回）") %} 
SUMMARY_LANGUAGE=Japanese
ENTITY_TYPE_PROMPT_FILE={{ download_name }}
  • SUMMARY_LANGUAGE=Japanese: 既定は English。英語のままだとエンティティの説明や検索キーワードが英語になります。
  • ENTITY_TYPE_PROMPT_FILE（1.5.x）: 下の「設備保全向けのエンティティ種別」YAML を PROMPT_DIR/entity_type/ に置き、ファイル名を指定します。既定の種別には 設備・部品・原因・処置 がありません。
  • 埋め込みモデルは日本語に強いものを最初に決めて固定します。途中で変えると全件の入れ直しになります。
  • 数万件を入れる場合は、PostgreSQL などのストレージを使います（既定のファイル保存は小規模向け）。
{% endcall %} {% call ui.card("3. 分割（チャンク）の設定") %}
  • LIGHTRAG_PARSER を設定しない場合、1,200トークンの固定幅で分割され、日本語の文や記録の途中で切れることがあります。
  • 帳票: 1件がほぼ1チャンクに収まるので、既定のままで構いません。
  • 一覧表の記録ファイル: 一覧表の取り込み設定で「ファイル名にLightRAG用のヒントを付ける」をオンにする（.[legacy-R(chunk_ts=800,chunk_ol=0)] が付きます）か、サーバー側で LIGHTRAG_PARSER を legacy-R にします。
  • 投入後、文書の状態（doc_status）の parse_engine / chunk_opts で、実際にどう分割されたかを確認できます。
{% endcall %} {% call ui.card("4. 件数・ランキング・推移は集計ファイルで答える") %}

LightRAG は質問ごとに数十件程度の記録しか読みません。「今年いちばん止まった設備は？」「月ごとの件数は？」のような質問は、記録ファイルだけでは正しく数えられません。

一覧表の取り込みで作られる 集計ファイル（…_集計_月次_…、…_集計_設備別_…）と データセット説明（…_00_データセット説明.md）も一緒に入れてください。数値はアプリで計算済みです。

{% endcall %} {% call ui.card("5. 更新するときの手順") %}

このアプリは投入済みのファイルとの差分を管理しません。取り込みごとに、その取り込みの全ファイルを zip で渡します。

  1. 一覧表の完了画面で Markdownをまとめてダウンロード（zip） を押します。
  2. 同じファイル名のものが LightRAG に入っていれば、LightRAG で先に削除します（1.5.x は同じ名前だと 409 になり、入れ直せません）。
  3. LightRAG の処理が終わる（idle になる）のを待ちます。
  4. zip の RAG投入用/ のファイルを LightRAG に入れます。管理用_RAGには入れない/ は入れません。

帳票は、確定し直したものだけを「削除してから入れ直す」で更新します。

{% endcall %} {% call ui.card("設備保全向けのエンティティ種別（YAML）", id="entity-types") %}
